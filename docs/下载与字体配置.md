# 下载与字体配置说明

## 本软件用的是什么字体？

固定字体为 **华文中宋（STZhongsong）**，文件名为 **`STZHONGS.TTF`**。
软件的 8～16 字排版按该字体设计，不会自动使用其他系统字体替代。

## 字体需要自行解决

**GitHub 开源源码和公开 Windows 下载包均不附带该字体。**
华文中宋属于第三方字体，不包含在本项目的 MIT 许可证中。请自行从合法渠道获取字体，并确认你的使用场景具有相应授权；本项目不提供字体下载或字体授权。电脑上已安装字体，不代表本下载包已配置完成，软件需要下述目录中的独立字体文件。

字体原文件版权信息为 Changzhou SinoType Technology Co., Ltd.（常州华文印刷新技术有限公司），以字体随附许可和权利人说明为准。

## Windows 便携版

1. 下载 Release 中的 `seal-generator-v1.1.0-Windows-no-font.zip` 并完整解压。
2. 将自行取得授权的 `STZHONGS.TTF` 放入解压目录下的：

   ```text
   印章生成器/
   ├─ 印章生成器.exe
   └─ _internal/
      └─ resources/
         └─ fonts/
            └─ STZHONGS.TTF    ← 自行放入这里
   ```

3. 双击 `印章生成器.exe`。电脑不需要安装 Python。

请保留整个程序文件夹，不能只复制 EXE。**未配置字体时，程序会提示固定字体不存在，无法进入正常生成流程；这不是下载损坏。** 请勿把其他字体改名为 `STZHONGS.TTF`，否则排版结果无法保证。字体文件也不会因为放入上述目录而自动取得使用或再分发授权。

## 从源码运行或自行打包

将自行取得授权的字体放在项目根目录的 `resources/fonts/STZHONGS.TTF`，然后按项目 README 安装依赖、运行或打包。完整渲染和界面测试也需要该字体。未放入字体前可以运行 README 中的不依赖字体测试子集。
